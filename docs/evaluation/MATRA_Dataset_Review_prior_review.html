Important interpretation and audit notes

  • The raw corpus contains band-gap and energy columns, but the current Atom2Vec training uses only formula. No band-gap preservation model is implemented.
  • The corpus has compositions and properties, not crystal coordinates. Site-aware generation needs separate host structures.
  • Benchmark site fields are evaluation annotations, not inputs to the present similarity engines.
  • Primary cases cover 9 distinct target elements. Broad engine coverage is not equivalent to broad validated accuracy.
  • Three electronegativity values are missing: He, Ne and Ar. Five elements have flagged imputation: Kr, Xe, At, Rn and Fr.
  • The polarizability unit in the milestone report needs correction: the builder directly copies Mendeleev values. See Mendeleev source documentation. Stored values below are unchanged.
  • Fr thermal conductivity is assigned 15.0 directly. The claimed extrapolation needs a reproducible derivation.
  • Elements Z=95 through 118 are outside the master table. Unsupported elements should receive a clear status, not invented descriptors.
